← All sets How it works
Workflow: fill in the form → Add to export → Download puzzles.json → drop that file (and your artwork into images/) into your GitHub repository. The live site reads puzzles.json at startup, so no rebuild is needed.
The export starts empty on every visit — you are building a fresh puzzle set. To continue an existing one, load it with the buttons on the right.

Field reference

FieldMeaning
idUnique slug. Also used to detect an unfinished run, so don't rename puzzles casually.
answerOptional. Integer 0–100 (the odds). Leave it out and the puzzle is a pure "how to play" puzzle — no odds slider at all.
stepsThe correct action sequence as an array, e.g. ["block 2d", "dodge"]. Rendered with the buttons' labels, so use those exact words.
taskThe situation and the mission. Markdown subset is supported.
questionThe line right above the optional odds slider, e.g. "What is the chance you knock the carrier down? (%)".
legendConditions: who has which skills in this puzzle. Each entry is { name, skills[], note, color }; color is one of blue, red, green, yellow, purple, white — or omitted for no colour. It is only cosmetic: the puzzle reads the same without it.
solutionFull worked solution, revealed after submitting.
actionsOptional per-puzzle override of the buttons. Defaults to block 1d, block 2d, block 3d, block uphill, dodge, gfi, pass, catch plus clear.
exactOptional exact value shown next to the odds, e.g. 5/9 = 55.56%.
imageEither a path relative to the site root (images/your-file.png) or a full link to an image (https://…/pitch.png). Any http(s) URL, protocol-relative //… and data:image/… are accepted; other schemes are rejected. The play page requests remote images without a referrer so hotlink protection is less likely to blank them.
toleranceOptional per-puzzle tolerance in percentage points (default 5).
